# Prajyot Satarde — Developer Portfolio

Next.js portfolio for Prajyot Satarde, Mathematics & Computing at IIT Dharwad.

## Local development

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run lint
npm run build
```

## Environment

Copy `.env.example` to `.env.local`. GitHub data is optional; contact delivery requires Resend configuration.

## Deploy

Import `PrajyotXDev/Missing-No` into Vercel as a Next.js project.
